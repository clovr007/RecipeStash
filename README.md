# 📖 RecipeStash

A calm, aesthetic personal cookbook web application built with **Django REST Framework** and **React**. RecipeStash provides a cozy, minimalist space for users to create, organize, and view their favorite recipes.

---

## ✨ Features

* **Authentication & Authorization:** Secure user registration, JWT/session authentication, and protected recipe routes.
* **Full Recipe CRUD:** Create, read, update, and delete recipe entries.
* **Cozy Cookbook UI:** Clean serif typography, soft pastel tones, and distraction-free layouts.
* **Context-Driven State:** Global authentication management using React Context.
* **Responsive Layout:** Grid layout optimized across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

* **Frontend:** React, React Router, Axios, Custom CSS
* **Backend:** Python, Django, Django REST Framework (DRF)
* **Database:** SQLite (default)
